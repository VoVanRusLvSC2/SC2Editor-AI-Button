# Подключение Codex, Claude и MCP

## Реализовано

- DLL открывает отдельное окно AI с историей по центру, списком чатов справа, выбором модели и отдельными настройками провайдера.
- Локальный процесс-посредник общается с DLL по приватным унаследованным каналам ввода и вывода. Сетевой порт не открывается; секреты в проект не записываются.
- Codex app-server: авторизация через установленный Codex, доступные локальные чаты, последние 100 блоков истории, создание и продолжение диалогов, поток ответа, выбор модели, остановка, вопросы пользователя и подтверждения команд, файлов и дополнительных прав.
- Claude Agent SDK: локальные сессии и их история, создание и продолжение, поток ответа, модель и отмена, обработка запросов разрешений. Для запуска пользователь отдельно устанавливает SDK и входит в аккаунт Claude. Авторизованная отправка требует отдельной проверки на этом компьютере.
- Кодекс использует настроенные серверы MCP. Для Claude берётся конфигурация `sc2editor` из Codex, если она доступна. Индикатор сообщает наличие сервера и инструментов; активная карта и привязка экземпляра редактора не проверяются автоматически.
- История интерфейса ограничена последними 200 000 символов. Некоторые формы MCP (elicitation), секретные вопросы и неподдерживаемые серверные запросы отклоняются с сообщением; дополнительные виды подтверждений нужно добавить по мере проверки.

## Дальнейшая проверка

1. Завершить вход в Claude, проверить реальный ответ и продолжение локальной сессии на тестовом проекте.
2. Проверить доступ Claude к SC2 MCP и выполнить безопасный запрос к тестовой карте.
3. Реализовать надёжную проверку текущей карты и экземпляра редактора, смену карты и восстановление MCP.
4. Доработать сложные формы MCP, пагинацию полной истории и другие размеры интерфейса.

Источники: [OpenAI Docs: Codex app-server](https://developers.openai.com/codex/app-server/) и [Claude Agent SDK: sessions](https://code.claude.com/docs/en/agent-sdk/sessions).
