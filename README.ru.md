# Кнопка AI для редактора StarCraft II

Экспериментальное расширение добавляет кнопку **AI** перед кнопкой SC2. Открыв её, можно читать доступные локальные чаты Codex, создавать и продолжать диалоги, выбирать модель и получать ответы прямо в отдельном окне редактора. Слева находится список чатов, по центру — переписка, а в настройках выбирается Codex или Claude. Пункт «＋ Новый чат» находится в списке; кнопка отправки во время ответа становится кнопкой остановки. Кнопка AI выделена, пока активно окно AI; повторный клик не снимает выделение.

## Запуск

1. Установите **Node.js 18.14 или новее** с npm и запустите 64-битный StarCraft II Editor версии **5.0.17.98310**.
2. Распакуйте архив в отдельную папку и запустите `Start AI Button.cmd`.
3. Откройте окно **AI**. Для Codex нужно установленное и авторизованное приложение Codex или совместимая команда `codex.exe`.
4. Для Codex выберите его в настройках AI и нажмите «Войти в Codex». Войдите в аккаунт ChatGPT в браузере. Уже подключённый аккаунт Codex обычно используется автоматически.
5. Для Claude запустите `Setup Claude.cmd`, откройте Claude Console из настроек AI, войдите по почте и создайте API-ключ. Добавьте ключ в пользовательскую переменную среды Windows `ANTHROPIC_API_KEY` и перезапустите редактор. API оплачивается отдельно; подписку Claude.ai в этом стороннем приложении Agent SDK использовать нельзя. Не отправляйте ключ в чат.

Расширение предназначено для Windows x64 с указанной версией редактора. Путь установки игры и папку пользователя задавать не нужно; окно ищется по его структуре, независимо от языка заголовка. Проверка версии EXE и структуры панели нужна, чтобы не подключаться к неподдерживаемой версии. Сборка и локальные тесты проверены на Windows 11 x64; автоматическая сборка также запускается на Windows Server 2022 и 2025. Это не подтверждает работу на каждой версии Windows, каждом масштабе экрана и языке редактора. Для работы с чатами дополнительно нужны совместимые Node.js и Codex или Claude.

Если открыто несколько редакторов, укажите процесс в командной строке: `SC2AILoader.exe --pid НОМЕР_ПРОЦЕССА`. Загрузчик не изменяет файлы игры. DLL остаётся в редакторе до его закрытия; после перезапуска редактора запустите загрузчик снова.

## Возможности и ограничения

- Codex подключается через app-server установленного приложения, использует существующую авторизацию и показывает доступные локальные чаты. Удалённые и облачные чаты доступны только если их предоставляет локальный сервер.
- Claude использует Claude Agent SDK и его локальные сессии. Для этого приложения нужен отдельно оплачиваемый API Claude Console ([правила Anthropic](https://code.claude.com/docs/en/legal-and-compliance), [создание ключа](https://platform.claude.com/docs/en/get-api-key)). Чаты на сайте Claude не обязательно совпадают с сессиями Claude Code.
- Настроенный в Codex сервер `sc2editor` передаётся Claude; для Codex используются его обычные настройки MCP. При каждом сообщении помощник получает путь карты и идентификатор окна редактора. Если путь сокращён в заголовке, расширение сопоставляет его с историей редактора и отмечает это; при неоднозначности путь не выбирается. Подключение и применение изменений зависят от доступных инструментов `live.*` в MCP. Индикатор имени карты сам по себе не подтверждает подключение MCP.
- MCP `live` работает через сохранённую карту и отдельную рабочую копию. Сначала сохраните несохранённые изменения в редакторе; применение результата требует подготовки и открытия контрольной копии, а не напрямую меняет содержимое памяти редактора.
- Codex может напрямую изменять файлы в рабочей папке открытой карты; для других путей и действий может потребоваться подтверждение. При запросе разрешения на команду или файлы появится подтверждение. Обычные вопросы AI можно отвечать в поле ввода. Некоторые сложные формы MCP пока не поддерживаются и отклоняются. Режимы и разрешения самих установленных помощников также влияют на их поведение.
- Если Codex сообщает, что чат занят другим процессом, продолжите этот же чат в другом приложении Codex или создайте новый чат в редакторе. При отказе отправки текст и изображения остаются в поле ввода.
- Чаты Codex сгруппированы слева по проектам приложения, цвет значка папки берётся из настроек Codex; нажмите на название группы, чтобы свернуть или раскрыть её. Чаты Claude группируются по рабочей папке. Окно показывает последнюю часть истории длинных диалогов.
- Подписи и системные сообщения доступны на русском и английском языке; выбор определяется по меню редактора. Для остальных языков используется английский. Тексты пользователя и ответы AI не переводятся. Роли и события в истории выделены цветом; длинные команды показаны в сокращённом виде.
- К сообщению можно прикрепить до пяти картинок: вставьте их в поле ввода через Ctrl+V или выберите несколько файлов кнопкой «Картинка». У каждой миниатюры своя кнопка удаления. Поддерживаются PNG, JPEG, GIF и BMP; картинки преобразуются в PNG. Ограничение после преобразования — 7 МиБ на картинку и 20 МиБ на все вложения. Для истории отправленные копии сохраняются во временной папке `SC2EditorAI`; неотправленное вложение удаляется при отмене или закрытии окна.
- Это отдельное окно расширения, а не зарегистрированный внутренний модуль редактора. Кнопки переключения модулей в нём работают; несвязанные кнопки редактирования отключены. Другие версии редактора, все варианты интерфейса и масштабы экранов ещё не проверены полностью.
