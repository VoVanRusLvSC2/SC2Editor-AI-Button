# Кнопка AI для редактора StarCraft II

Экспериментальное расширение добавляет бело-синюю кнопку **AI** размером с другие
кнопки на верхней панели редактора, перед кнопкой SC2. Она открывает отдельное
пустое окно **AI**, развёрнутое на весь экран. Повторное нажатие
показывает уже открытое окно; после закрытия его можно открыть снова. Чата и MCP
пока нет.

1. Запустите 64-битный редактор StarCraft II и откройте карту.
2. Распакуйте ZIP в отдельную папку.
3. Запустите `Start AI Button.cmd` из этой папки.
4. Нажмите **AI** на панели редактора. После перезапуска редактора заново
   запустите `Start AI Button.cmd`.

Поддерживается редактор версии **5.0.17.98310 x64**. Загрузчик подключает DLL
к работающему процессу редактора; установленные файлы игры он не меняет. DLL
работает до закрытия редактора. Окно пока отдельное, а не закреплённая панель.
Если открыто несколько редакторов, используйте из командной строки
`SC2AILoader.exe --pid НОМЕР_ПРОЦЕССА`.

Это ранний прототип. Сначала проверьте его на копии карты; другие версии редактора,
все варианты интерфейса и масштабы экрана ещё не проверены полностью.
